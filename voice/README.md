# voice

Python helper bundled with the companion app as a Tauri sidecar. Adapted from backtalk (AGPL-3.0-or-later, see `CREDITS.md`). Runs the agent session through the user's own installed Claude Code (Claude Agent SDK), speech-to-text, and the voices (Kokoro free and local, ElevenLabs on the user's own key from the system keychain). Never handles Claude credentials (see `SECURITY.md`).
