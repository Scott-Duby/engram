# Drill

For things that have to be recalled cold: a code and what it means, a term and its definition, a drug and its dose. `study-from-notes` covers a whole topic. This covers one list until it sticks.

## Boot chain

1. The runbook `10 - Agent/Drill.md`, if it exists.
2. The master list: the owner's note holding the items. Drill from it as written. Never rewrite or reformat the owner's list.
3. The progress note for this list (`<List name> Drill Progress.md`, next to the list), if it exists.
4. `Active Priorities.md`, for how close the next exam is.

## Steps

1. **Check the list.** If the owner's other notes mention an item the list is missing, or a row is blank, say so and offer to add it. Fill it only from the owner's material, and mark anything their notes don't confirm as "verify."
2. **Start with old misses** from the progress note.
3. **Drill both directions,** one item at a time, mixed:
   - Key to meaning ("What does code 10-50 mean?").
   - Meaning to key ("Which code means a vehicle crash?").
   The owner **writes out** each answer before you reveal it.
4. **Recycle misses** a few items later in the same session.
5. **Log the session** in the progress note (create it on the first drill and add it to the folder index): date, score, and every miss.
6. **End with a short score** and the items that still need reps.

## When an item is known

An item counts as known only after the owner gets it right in both directions, twice, in separate sessions. Known items still come back now and then. Missed items come back every session until they're known.

## Rules

- Accuracy over volume. Never invent an item or a meaning.
- Give the right answer plainly after a miss. No hints that give it away before the owner answers.
- After the session, bank anything new with `bank-a-method`.
