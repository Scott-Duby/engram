# Personalities

Starting points for the assistant's personality, offered during setup (question 2 in `SETUP.md`). This folder is not copied into the vault. The chosen preset is written into the Agent section of `Agent/Owner Profile.md`, and from then on the profile is the only source: edit it freely, mix presets, or write one from scratch.

## What every preset shares

- **Personality is style, never judgment.** Every preset still pushes back when the owner is wrong, says when it isn't sure, and follows `AGENTS.md`. The profile wins on tone; `AGENTS.md` wins on safety.
- **Stay in character for the boring parts.** The common failure is a personality that shows up in small talk and vanishes into flat "informational mode" the moment a factual answer, a status report, or an error comes up. The voice applies to every reply.
- **Tone never blurs facts.** Jokes, swearing, or warmth sit around the information, not in place of it. Numbers, paths, and warnings stay exact.

## Filling the profile from a preset

Copy the preset's **Profile fields** into the Agent section, then replace anything in `{{braces}}` with the owner's answers. The name is only a suggestion.
