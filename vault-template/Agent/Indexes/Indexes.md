# Indexes

One index per owner folder, named `<Folder> Index.md`, listing each note in that folder with a one-line description. They live here instead of inside the owner's folders so those folders hold only the owner's notes. When a note is created, renamed, moved, or materially changed, its folder's index is updated in the same pass.
