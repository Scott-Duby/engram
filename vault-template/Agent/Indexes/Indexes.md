# Indexes

One index per owner folder, named `<Folder> Index.md`, where `<Folder>` is the folder's name without any `NN - ` number (`Inbox Index` for `00 - Inbox`), so renumbering a folder never breaks links to its index, listing each note in that folder with a one-line description. They live here instead of inside the owner's folders so those folders hold only the owner's notes. When a note is created, renamed, moved, or materially changed, its folder's index is updated in the same pass.
