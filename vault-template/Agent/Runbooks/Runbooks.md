# Runbooks

How recurring jobs are done in this vault, and how the assistant reaches each outside system. A skill holds the general method; a runbook here holds what's specific to this owner (their sources, their quirks, the method that worked, the dead end to skip). The matching skill reads its runbook first, and the runbook wins where they disagree. Format: `Agent/Templates/Runbook Template.md`, or the `bank-a-method` skill.
