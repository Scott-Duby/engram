# Agent

The assistant's folder. Everything the assistant needs to do its job lives here, so the rest of the vault stays the owner's. The owner can ignore this folder; the assistant keeps it current.

## Notes
- [[Vault Settings]]: how this vault was set up (numbered folders, tags as folders, daily notes, templates). Read before writing anything outside this folder.
- [[Owner Profile]]: the assistant's name and personality, and the owner's preferences, schedule, and standing calls.
- [[Vault Map]]: what each of the owner's folders holds.
- [[Active Priorities]]: the single queue of open work.

## Folders
- `Indexes/` ([[Indexes]]): one index per owner folder, listing its notes.
- `Log/` ([[Log]]): the assistant's dated log of every change.
- `Runbooks/` ([[Runbooks]]): how recurring jobs are done, and how the assistant reaches each system.
- `Templates/`: templates for the assistant's own notes (present only if chosen at setup).
